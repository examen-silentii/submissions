# Submissions to Examen Silentii (ExSil)

This repository holds submissions to [Examen Silentii](https://examen-silentii.github.io), an open journal of independent, reproducible examinations of scientific software and public research data.

**Submissions are not yet open.**

## How it works

- **Authors** submit by opening a new issue with the *Submit an examination* form.
- **Reviewers** rerun the authors' test and complete the [reviewer checklist](REVIEW_CHECKLIST.md) in a comment on the issue.
- **Maintainers** of the examined software or data are invited to respond in the same issue.
- Review is open: the whole discussion remains public as part of the record.

Please read the [submission requirements](https://examen-silentii.github.io/submit/) and [policies](https://examen-silentii.github.io/policies/) before submitting.
